# Velora Architecture

## Goal

Build the first version of Velora Analyst.

The MVP allows business owners to upload files and receive AI-powered business insights.

## System Components

### Frontend

Responsible for the user interface:

- Landing page
- File upload
- Results display

### Backend

Responsible for processing:

- Receive uploaded files
- Extract data
- Send data for AI analysis
- Return insights

### AI Layer

Responsible for:

- Understanding business data
- Finding problems
- Finding opportunities
- Creating recommendations

### Storage

Responsible for:

- Temporary file storage
- User analysis data

## MVP Flow

User uploads files

↓

Backend processes files

↓

AI analyzes business data

↓

User receives:

- Summary
- Problems
- Opportunities
- Action Plan
