# Velora Setup Guide

## Requirements

Before running Velora, install:

- Node.js
- npm


## Installation

Open the project folder and run:

npm install


## Start Server

Run:

npm start


## Open Application

Open your browser and visit:

http://localhost:3000


## Workflow

1. Open Velora

2. Upload business file

3. Select Excel, PDF, or Word file

4. Click Analyze

5. Velora processes the file

6. View Business Analysis Report


## Supported Files

- Excel (.xlsx)
- PDF (.pdf)
- Word (.docx)


## Server Technology

Backend:

- Node.js
- Express
- Multer


## File Processing

Velora supports:

- XLSX file reading
- PDF text extraction
- Word document extraction
