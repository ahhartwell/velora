# Velora UI Plan

## Goal

Create a simple interface that helps business owners start analysis quickly.

## First Screen

The user sees:

- Velora logo/name
- Tagline: Know what to do next.
- Upload Files button
- Ask anything about your business

## User Flow

1. User opens Velora.
2. User uploads PDF or Excel files.
3. Velora analyzes the files.
4. User receives business insights.

## MVP Screens

### 1. Landing Page
- Introduction
- Upload button

### 2. Analysis Page
- Processing status
- AI analysis results

### 3. Report Page
- Summary
- Problems
- Opportunities
- Action Plan
- Export PDF
